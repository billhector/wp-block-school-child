Code

Inline code looks like register_block_pattern() and renders in JetBrains Mono. A fenced block:

add_action('init', function () {
  register_block_pattern('wpbs/hero', [
    'title'    => 'Hero',
    'category' => 'wpbs',
    'content'  => '<!-- wp:heading -->...',
  ]);
});
